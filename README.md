# orbital

a tiny local deploy system

## Install

```sh
curl -LsSf https://raw.githubusercontent.com/rkvmar/orbital/main/install-remote.sh | sh
```

## Usage

```sh
orbital launch <git-url> [name]
orbital update <name>
orbital config <name>
orbital env <name>
orbital stop <name>
orbital start <name>
orbital status
orbital log <name>
orbital remove <name>
```
